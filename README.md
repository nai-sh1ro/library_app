# Library App

Веб-приложение для ведения личной библиотеки: поиск и добавление книг,
управление коллекцией и статусами чтения.

## Возможности

- Регистрация, вход и профиль пользователя
- Добавление, изменение статусов и удаление книг из личной коллекции
- Поиск, фильтрация, сортировка и постраничное отображение книг
- Отправка обратной связи через Telegram API

## Технологии

- Node.js и Express
- EJS
- Sequelize
- SQLite

## Установка и запуск

1. Склонируй репозиторий и перейди в его папку.
2. Установи зависимости: `npm install`
3. Создай `.env`.
4. Запусти приложение: `npm start`

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `PORT` | Порт приложения, если он настраивается через окружение |
| `SESSION_SECRET` | Секретный ключ для подписи пользовательских сессий |
| `GOOGLE_BOOKS_API_KEY` | API-ключ для запросов к Google Books API |
| `TG_BOT_TOKEN` | Токен Telegram-бота |
| `CHAT_ID` | ID чата, куда бот отправляет обратную связь |
